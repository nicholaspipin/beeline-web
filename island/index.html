The Island, every trip state

What the Lock Screen card, the Dynamic Island and the Live Trip widget show at each size during a trip. Since 2026-09-15 the shell composes each surface as nodes (laLayout.js) and the Swift only draws them, so this page renders the very nodes the phone gets: a countdown only for a bus that is really being tracked, minutes from the distance left for walks, clock times for scheduled buses.

Rules the Island keeps

  • Honey appears only for LIVE and your stop being next. Red only for running late and an operator-filed service alert.
  • A scheduled bus is a clock time with “Scheduled”, never a countdown. When the live feed goes quiet the time dims and says when it was last live.
  • “+6m” / “+6 late” is an estimate of minutes late for the class; the expanded Island says “About 6 min late for A327”.
  • The Island exists during a trip and ends on arrival. A class countdown or a trip home outside a trip is not a Live Activity today.
  • Each fact once: a waiting bus is titled “F bus”, a ride “Get off at …”, and LIVE / Scheduled sits under the number it qualifies.
